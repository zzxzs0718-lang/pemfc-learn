# PEMFC 《质子交换膜燃料电池水热管理》 · 边读边学

《质子交换膜燃料电池水热管理》（焦魁 等）的伴读网页。离线可用，双击 `index.html` 即可。

## 怎么用

1. 双击 **index.html**（推荐 Chrome / Edge）。
2. 左侧目录按章走；每节右上有「标记已读」，进度存在本机浏览器（localStorage）。
3. 带「交互演示」的地方一定要拖动滑块——水热管理是趋势问题，看一遍比读十遍有用。
4. **章末三层**：选择题自测（查漏）→ **延伸思考**（查迁移，答案折叠，先写三行）→「标记已读」。
5. 侧栏工具页：**开读准备**、**延伸思考**（全部开放题汇总，可按类型筛选）、**公式速查**、**术语表**。

## 目录结构

```
pemfc-learn/
  index.html            入口
  SPEC.md               内容创作契约
  SPEC-EXTEND.md        延伸思考的写作契约
  css/style.css         全部样式（深色主题、打印样式）
  js/app.js             路由、渲染、进度、测验、搜索、图片块
  js/content/ch1..8.js  八章内容（window.CONTENT["chN"]：sections/quiz/terms/extend）
  js/demos/*.js         八个交互演示（window.DEMOS[id]）
  assets/img/           数据图（light/dark 两版）与照片，来源见 CREDITS.md
```

## 图片来源与许可

只用可授权素材，逐条记录在 `assets/img/CREDITS.md`：两张 Wikimedia Commons 照片（CC BY 2.0 / 无已知版权限制），三张数据图由本项目用 matplotlib 生成。

## 想自己改内容

改 `js/content/chN.js` 即可，结构见 `SPEC.md` / `SPEC-EXTEND.md`。刷新页面就生效，不需要构建。

## 小技巧

- 顶栏 ◐ 切换深浅色（也支持 `?theme=dark`）。
- 顶栏圆环是全书阅读进度；「重置学习进度」在侧栏底部。
- 打印时自动隐藏导航并展开目录；「延伸思考」的答案仍保持折叠。
- 数据图有深浅两版，切换主题会自动换图。

## 说明

正文中的「（p.N）」指**这份 PDF 的页序号**（书内印刷页码 = PDF 页码 − 20）。
交互演示与数据图均为教学简化模型（集总参数、Springer 关联式、Tafel 型极化），用于说明趋势与量级，不作设计依据——简化点写在各图图注里。
